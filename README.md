# PIXEL PC BUILDER ACADEMY — เกมสื่อการสอนการประกอบคอมพิวเตอร์ (Pixel Art)

เว็บเกมสื่อการสอนการประกอบคอมพิวเตอร์แบบ 2D Interactive แนว **16-bit Pixel Art** ภาษาไทยเต็มรูปแบบ เปิดเล่นได้ทันทีผ่านเบราว์เซอร์โดยไม่ต้องติดตั้งโปรแกรมเสริม พร้อมระบบเลือกระดับความยาก และระบบส่งออกรายงานคะแนน/เกียรติบัตรสำหรับห้องเรียน

## วิธีเปิดใช้งาน
1. ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดด้วย Google Chrome / Microsoft Edge / Firefox ได้ทันที
2. รองรับทั้งการ **คลิกเลือกแล้วคลิกวาง** และ **ลากวาง (Drag & Drop)** เหมาะสำหรับทั้งคอมพิวเตอร์ แท็บเล็ต และกระดานอัจฉริยะในห้องเรียน

## ฟีเจอร์ที่อัปเดตเพิ่มเติม
- **ระดับความยาก 3 ระดับ (Difficulty Levels)**:
  - `🟢 ง่าย (Easy)`: มีไฮไลต์ช่วยนำทางตลอด คำใบ้ไม่จำกัด โซนทาซิลิโคนกว้าง หักคะแนนผิดพลาดน้อย (-2)
  - `🟡 ปานกลาง (Normal)`: มาตรฐาน คำใบ้ 3 ครั้งในโหมดทดสอบ โซนทาซิลิโคนมาตรฐาน (-5)
  - `🔴 ยาก (Hard / สอบปฏิบัติ)`: ไม่มีคำใบ้ ไม่ไฮไลต์ตำแหน่งขณะเลือกอุปกรณ์ โซนทาซิลิโคนแคบ หักคะแนนสูง (-10)
- **ระบบข้อมูลผู้เรียน & ส่งออกคะแนนสำหรับห้องเรียน (🎓 ส่งคะแนนครู)**:
  - กรอก ชื่อ-นามสกุล, รหัสนักเรียน, ชั้น/ห้อง เพื่อบันทึกโปรไฟล์ผู้เรียน
  - **ดาวน์โหลดเกียรติบัตร Pixel Art (PNG)** พร้อมรหัสตรวจสอบความถูกต้อง (`Verify Code`)
  - **ดาวน์โหลดไฟล์คะแนน CSV (UTF-8)** เปิดใช้งานใน Microsoft Excel / Google Sheets ได้ทันที
  - **คัดลอกข้อความสรุปผลคะแนนส่งครู** หรือ **พิมพ์ใบรายงานผล** ออกเครื่องพิมพ์ได้ทันที

## 5 โหมดการเรียนรู้ครบวงจร
1. **โหมด 1: ฝึกสอนทีละขั้นตอน (Guided Tutorial)** — อาจารย์วัช แนะนำการประกอบครบ 12 ขั้นตอน พร้อมคำอธิบายหน้าที่อุปกรณ์และข้อควรระวัง
2. **โหมด 2: ทดสอบประกอบเอง & จับเวลา (Timed Challenge)** — ประกอบเครื่องด้วยตนเอง จับเวลา นับคะแนนความแม่นยำ และตัดเกรด S–D
3. **โหมด 3: ภารกิจจัดสเปกตามงบประมาณ (Budget & Compatibility Missions)** — 8 โจทย์ลูกค้า ตรวจเช็กความเข้ากันได้จริง (AM4/AM5/LGA1700, DDR4/DDR5, Cooler TDP, กำลังไฟ PSU และงบประมาณ) แล้วนำไปประกอบเครื่องจริง
4. **โหมด 4: ศูนย์ซ่อม & จำลองหน้าจอ BIOS/POST (Realistic Steps & Troubleshooting)** — ฝึกทาซิลิโคน (Thermal Paste), เดินสายไฟ (24-Pin / 8-Pin CPU / 8-Pin PCIe / CPU_FAN), ดูทิศทางลม Airflow, ฟังเสียง POST Beep และซ่อมคอมพิวเตอร์ 8 เคส
5. **โหมด 5: สารานุกรมอุปกรณ์ & แบบทดสอบวัดผล (Encyclopedia & Quiz)** — คลังความรู้ฮาร์ดแวร์ 10 หมวด พร้อมแบบทดสอบ 20 ข้อ เฉลยละเอียด และระบบสะสมเหรียญตราความสำเร็จ 12 เหรียญ (บันทึกความก้าวหน้าอัตโนมัติ)
